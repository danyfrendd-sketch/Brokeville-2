# Brokeville 2

**Статус:** ранний прототип. Сейчас в репозитории сосуществуют две разные задачи, и их нельзя смешивать без явного решения.

- **Игровая прогулка по Пиетарсаари / Jakobstad:** `play.html` загружает готовую 3D-модель `map/preview/pietarsaari_3d.glb`.
- **Карта Brokeville по схематическому чертежу:** `index.html` показывает исходное изображение с сеткой; геометрия улиц и зданий ещё не обведена и масштаб не откалиброван.

## Запуск

- [Просмотр чертежа](./index.html)
- [3D-прогулка](./play.html)
- [Схема файлов и статус проекта](./PROJECT_AUDIT.md)

На GitHub Pages откройте `/Brokeville-2/` для схемы или `/Brokeville-2/play.html` для 3D-прогулки. В 3D-прогулке `?glb=v1` выбирает текущую модель. `?glb=v2` предназначен для отдельной модели `map/preview/pietarsaari_3d_v2.glb`; пока её нет, используйте v1.

## Источник истины и безопасность

- Опубликованная модель: `map/preview/pietarsaari_3d.glb`. Не перезаписывать её автоматической сборкой без отдельного ревью.
- Исходник схемы Brokeville: `map/references/city_map.json`, `map/anchors-v1.json` и `map/map-layout.json` — ориентиры/черновые данные, не точный CAD-план.
- Скрипт `map/tools/build_pietarsaari_3d.py` читает `map/data/pietarsaari_osm.geojson`, но пишет результат в `map/data/pietarsaari_3d.glb`. Это **не** тот путь, который сейчас загружает игра. Не запускать сборку в надежде обновить опубликованную модель, пока пути и исходные данные не согласованы.
- Внешняя картинка в `index.html` загружается с Catbox; это отдельная внешняя зависимость, не локальная копия.
- Сборка/проверки не должны автоматически скачивать новые OSM-данные или менять геометрию опубликованной карты.

## Проверки

Pull request и push должны запускать базовую проверку структуры, JSON и синтаксиса Python. Это не заменяет проверку в браузере: отдельно нужно проверить загрузку GLB, управление на телефоне/ПК, высоту спавна и столкновения.

Подробная инвентаризация, обнаруженные несоответствия и список следующих действий — в [PROJECT_AUDIT.md](./PROJECT_AUDIT.md).
