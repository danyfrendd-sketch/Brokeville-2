# Brokeville 2 — Reference Images

Upload the original map blueprint and any supporting screenshots into this folder.

## How to add images from a phone
1. Open the repository: https://github.com/danyfrendd-sketch/Brokeville-2
2. Open `map` → `references`.
3. Tap **Add file** → **Upload files**.
4. Choose the blueprint image from Photos/Files. PNG or JPG is best.
5. Commit the upload to the `main` branch.

Recommended filename for the main map: `blueprint.png` (or `blueprint.jpg`).

Please upload the original image at the highest available resolution. Do not crop out the scale bar, legend, map edges, or labels.

This is a folder for image uploads; this Markdown file is only an instruction note. The 3D model has not yet been traced from the blueprint.
